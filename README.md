# RF DSP Lab

一个面向无线电、射频与数字信号处理初学者的中文交互式实验室。

无需安装依赖，直接在浏览器中观察信号在时域和频域中的变化，并通过可调参数建立采样、FFT、窗函数和滤波的直觉。

![RF DSP Lab 预览](assets/preview.png)

## 功能

- 正弦波与方波信号源
- 双音信号和可控噪声
- 时域波形与 FFT 频谱
- 两张图独立缩放和平移
- 自动适配当前可见数据
- 悬停十字线与坐标读数
- 滚轮缩放横轴，`Shift + 滚轮`缩放纵轴
- 矩形窗、Hann 窗、Hamming 窗和 Blackman 窗
- 一阶低通与高通滤波
- 奈奎斯特频率和混叠提示
- 四个引导式实验预设

## 快速开始

直接打开 `index.html` 即可使用。

也可以启动任意静态文件服务器：

```powershell
npx serve .
```

然后在浏览器中访问终端显示的本地地址。

## 图表操作

| 操作 | 功能 |
| --- | --- |
| 鼠标拖拽 | 平移当前视图 |
| 鼠标滚轮 | 缩放横轴 |
| `Shift + 滚轮` | 缩放纵轴 |
| 双击图表 | 恢复默认视图 |
| `X+` / `X-` | 放大或缩小横轴 |
| `Y+` / `Y-` | 放大或缩小纵轴 |
| 自动 | 显示全部数据并自动适配纵轴 |
| 复位 | 恢复该图默认观察范围 |

## 学习路线

1. 基础信号、采样、FFT、窗函数与滤波
2. STFT、瀑布图与实时音频输入
3. AM、FM、ASK 与 FSK 调制解调
4. IQ 信号、星座图、眼图与符号率
5. IQ/WAV 文件导入与测量工具
6. 连接 SDR 硬件
